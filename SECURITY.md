# Security Policy

Anatomia Aperta 3D is a static website: it has no backend, user accounts or stored personal data, and embeds its 3D
models through the Sketchfab Viewer API.

## Reporting a vulnerability

If you find a security problem — for example in the site, its build tooling or its dependencies — please **do not open
a public issue**. Report it privately instead, either through
[GitHub private vulnerability reporting](https://github.com/tspiriev/Anatomia-Aperta-3D/security/advisories/new)
or by email to **3Datlas@pm.me**.

Please include a description of the issue, the steps to reproduce it and its potential impact. We will acknowledge
the report as soon as possible and keep you informed while it is addressed.

Issues in Sketchfab itself should be reported to Sketchfab.
